Project from course COP-3330C

The application is a multi-threaded program that stimulates battle between two characters. The program simulates a battle between two contenders: Gojo and Sukuna. 
Each contender runs as a separate thread and competes to defeat 200 curses first. The first contender to reach 200 wins the battle. There are no inputs for this 
application. The program outputs: the number of defeated curses, water breaks, and the winner of the battle.
